# Rúbrica APA 7 para revisión de protocolos

Aplicación web interactiva para revisión por pares.

## Incluye
- Datos completos del alumno revisor y del alumno evaluado.
- Modalidades: tesis, artículo de investigación y reporte de caso.
- Contador de palabras del título, con máximo de 25.
- Diez criterios con ponderación total de 100 puntos.
- Qué debe incluir cada apartado.
- Preguntas orientadoras.
- Rangos sugeridos de palabras.
- Lista de cotejo.
- Orientaciones APA 7.
- Retroalimentación por criterio.
- Calificación y clasificación automática.
- Guardado local de borrador.
- Descarga del informe completo en PDF.

## Publicación
Sube esta carpeta completa a Netlify. Después agrega la URL pública en Moodle.

## Nota
La biblioteca jsPDF se carga desde internet, por lo que la descarga del PDF requiere conexión.
